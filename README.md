# Sero Chocolates, final website

The finished site: home, shop, product, our story, membership, gifts, contact, cart, checkout and account.
Plain HTML, CSS and JavaScript, no build step. Everything this site needs is inside this folder.

- Open `index.html` to start. To put it on Vercel, import this repository and set the Root Directory to `Sero-Website-Main-Final`.
- `assets/img/` photos, `assets/motion.css` and `assets/motion.js` page animation, `assets/sero.js` catalogue and cart.
- Carts, orders and sign-in are demo data kept in the visitor's browser. No payment is taken and the forms do not send messages yet.
